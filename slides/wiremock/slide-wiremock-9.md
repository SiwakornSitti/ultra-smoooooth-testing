### Detailed Architectural Breakdown

### ⚡ Core Virtualization Engine (Feature Overview)

- **1. Precision Matching:** Route by path regex (`urlPathPattern`), query flags, headers, and semantic JSON AST.
- **2. Dynamic Templating:** Compute math, date offsets, and echo request IDs dynamically via Handlebars expressions.
- **3. Stateful Scenarios (FSM):** Model multi-step state transitions and token replay rejections in memory with sub-2ms resets.
- **4. Chaos & Fault Injection:** Simulate log-normal latency percentiles, dropped TCP sockets, and self-healing 503 retries.
