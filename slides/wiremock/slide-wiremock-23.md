# Precision Routing: Thai National IDs & UUIDs

### Route requests by URL regex patterns and validate payload structure without hardcoding test accounts

---

### Specification & Rule Matrix

| Architectural Component | Rule / Operational Specification |
| :--- | :--- |

---

### Architectural Rules
- **urlPathPattern**: Matches dynamic UUIDs (`[0-9a-f-]{36}`) generated by upstream auth sessions. Decouples tests from static database IDs.
- **matchesJsonPath**: RegEx predicate `^[0-9]{13}$` enforces valid 13-digit Thai National ID format.
- **Dynamic Timestamp**: `checkedAt: "{{now}}"` returns current UTC time to prevent test clock skew.
- **Parallel CI Scale**: 50 CI jobs can verify unique accounts simultaneously without database collision.


> 💡 **Production Pattern:** Parallel Safety: Decoupled from hardcoded database fixtures

### Presenter Notes

- Point out the URL regex: matches dynamic UUIDs generated by client or upstream auth.
- Emphasize the JSONPath expression: validates Thai citizen 13-digit ID without pinning test to a static DB record.
- Mention {{now}} templating: ensures timestamp assertions pass without clock skew.
